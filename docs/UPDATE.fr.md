# Mises à jour portables

Fermez StagePad Live avant de remplacer l’exécutable. Le ZIP Windows inclut le runtime ; shows, paramètres et pistes restent dans leurs dossiers.

**Paramètres > Mises à jour** consulte les releases stables de `Alessio278/StagePad-Live`. L’app vérifie version et SHA-256, conserve une copie précédente et tente de la restaurer si le démarrage échoue. Arrêtez l’audio et les séquences avant l’installation. La mise à jour garde le nom de l’exécutable installé.

Gardez des copies des shows et de l’audio avant de mettre à jour. La 1.1 enregistre en schéma 3, illisible par la version 1.0. Exportez le show avec audio pour transférer toutes les pistes : le JSON seul contient des références.

L’exécutable n’est pas signé et peut déclencher SmartScreen : consultez le [README](README.fr.md#windows-smartscreen). La lecture fonctionne hors ligne ; vérifier et télécharger les mises à jour nécessite internet.
