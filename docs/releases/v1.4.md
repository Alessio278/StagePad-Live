# StagePad Live 1.4

Three independent slot options are available in Setup.

- Block other audio starts while this slot plays. Already playing tracks continue. Attempts during playback or its fade-out are discarded, including MIDI and OSC commands on the blocked cue. Command-only slots and emergency actions remain available.
- Stop other audio slots on start. The new slot starts immediately. Each playing slot fades out using its own setting. Enabling both audio options also blocks subsequent launches.
- Hold for three seconds to activate an ordinary audio, MIDI or OSC cue. Releasing early cancels the cue. Use a momentary MIDI pad with Note Off. The existing emergency hold remains supported.

StagePad reads Shows from schemas 1 through 4. New options default to off. Saving in 1.4 writes schema 5. Keep a separate copy to reopen a Show in 1.3.


## Slot editor and settings

Global pause (previously Emergency) pauses all tracks at their current positions. Its three-second hold is optional. The editor groups outputs, show controls, activation and audio playback. The header displays the running application version.

Hover over a checkbox or selector for help. Long tips wrap and close when the pointer leaves the control, the window deactivates or tips are disabled. Settings saves the tooltip preference on this PC. Generic LED feedback uses a dedicated MIDI port and Note On messages. The selector shows when feedback is disabled. Connection and error messages appear below the controls.
