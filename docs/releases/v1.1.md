# StagePad Live 1.1

This release adds more practical MIDI/OSC configuration, clearer pad feedback and safer emergency triggering.

- MIDI/OSC commands start with editable show defaults. Changing defaults leaves existing commands unchanged.
- Duplicate and reorder commands, set waits and view sequence timing. MIDI and OSC run as independent lists.
- Configured pads have a subtle color tint; activation is more visible, including on MIDI/OSC-only slots.
- Emergency slots can require a continuous three-second hold, cancelled by early release or input loss.
- Exclusive + Marker slot action for the selected playing track in Setup, alongside a separate external MIDI LEARN binding.
- Per-slot volume percentages, a default for new slots, explicit apply-to-all while stopped, and retained mouse/MIDI volume on retrigger and save.
- New shows start with no actions selected; loading a track enables Audio.
- Slower wheel/trackpad scrolling, aligned action choices and compact +MARKER pad labels.
- Versioned executable `StagePad-1.1.exe`; support for two-part release tags and older updater assets.

## Downloads

- `StagePad-1.1.exe`: portable Windows x64 app, with runtime included.
- `StagePad-Live-1.1-Windows.zip`: app, license notices and update instructions.
- `StagePad-Live-1.1-Source.zip`: source, documentation and build workflows.
- `StagePad.exe`: identical compatibility asset for older updaters.
- `SHA256.txt`: checksums.

Back up shows before upgrading: 1.1 reads schemas 1/2/3 and saves schema 3; version 1.0 cannot open schema 3. Optional generic LED feedback is off by default and depends on the controller’s MIDI protocol.

The app is unsigned and Windows may display SmartScreen. Test audio and MIDI/OSC receivers with your performance setup before live use.
