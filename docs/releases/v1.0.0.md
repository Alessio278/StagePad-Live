# StagePad Live 1.0.0

First stable release of the consolidated Windows audio/MIDI/OSC show launcher.

- 1-100 pads with independent Setup/Live grids and four interface languages.
- Audio, MIDI and OSC actions, emergency pause and independent MIDI volume controls.
- Colored/labeled markers, marker-to-marker loops, per-marker MIDI/OSC and Setup-only marker capture LEARN.
- Integrated show management, New show, direct Save/Save as, rename/duplicate/delete and portable show/media packages.
- Background auto-save for named/unnamed shows, atomic backups, failed-write retry and session recovery.
- Standard AppData project path and non-destructive legacy migration.
- An applied loop shows only slow red visual feedback from the first Play, suppressing all colored marker flashes while keeping marker MIDI/OSC output.
- Playing + Marker inserts without opening a window; loop wraps suppress boundary flashes; colored cues own the frame for seven pulses over 1.82 seconds before red playback feedback returns.
- Unified dark rounded checkbox template with mint checks, keyboard focus and disabled/indeterminate states.
- Loops start directly at their first marker; slow red feedback remains exclusive while a loop is applied. Explicit Apply/Remove controls replace the checkbox.
- Quick marker insertion commits immediately and refreshes the list with a loop applied; the new-marker time field follows the cursor.
- Seven fast synchronized marker flashes with a stronger halo (150 ms on / 110 ms off).
- Fixed the empty-player cursor and light scrollbar intersection; consistent ASCII hyphens and updated documentation.

## Downloads

- `StagePad.exe`: self-contained Windows x64 application.
- `StagePad-Live-1.0.0-Windows.zip`: portable application, licenses, instructions and checksum.
- `StagePad-Live-1.0.0-Source.zip`: complete source including workflows and documentation.
- `SHA256.txt`: checksums of the distributed files.
- `RELEASE-CHECKS.md`: build/test environment and scope.

Close previous versions before starting. Shows normally live in `%LOCALAPPDATA%\StagePad\project`. Keep archived internal audio available when referenced by migrated shows.

This is a stable release, not a pre-release. The build is unsigned; Windows SmartScreen may display an unknown-publisher prompt. Automated/smoke checks do not replace testing real equipment. See the Windows checklist in the source package.
