# StagePad Live 1.2

- Set existing Markers as track start and/or end without changing the source file.
- Restore full playback at any time while the Slot is stopped.
- See the waveform inside the Loop in light gray; excluded Audio is dimmed.
- Updated README pages in Italian, English, Spanish and French, with clickable previews.

Show files now use schema 4. Back up your Shows before upgrading; versions 1.0 and 1.1 cannot open the new schema.

Before publishing, run Build.ps1 on Windows and complete docs/TESTING.md. Core and simulated integration checks do not cover native WPF, Windows drivers or real devices.
